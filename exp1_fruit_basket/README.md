# Experiment 1: Fruit Basket

A basic Flutter UI: a fruit basket screen built from core Material widgets and layouts.

## Features
- Material app with a scrollable fruit list/grid
- Core layout widgets (Column, Row, Card, ListView)
- Stateless/stateful widget fundamentals

## Tech stack
Flutter (Material 3)

## Run
1. Open this folder in VS Code (**File > Open Folder**).
2. In a terminal run `flutter pub get`.
3. Pick a device (Android phone, emulator or Chrome) from the bottom-right corner.
4. Press **F5** or run `flutter run`.
