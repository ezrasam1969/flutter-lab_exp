# Experiment 2: ShopEase Product Catalog

A shopping-style product catalog grouped by category.

## Features
- Product listing presented by category
- Reusable card widgets for products
- Clean Material 3 layout

## Tech stack
Flutter (Material 3)

## Run
1. Open this folder in VS Code (**File > Open Folder**).
2. In a terminal run `flutter pub get`.
3. Pick a device (Android phone, emulator or Chrome) from the bottom-right corner.
4. Press **F5** or run `flutter run`.
