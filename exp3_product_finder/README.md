# Experiment 3: Product Finder

Search and filter a product list in real time.

## Features
- Live text search ("Search products...")
- Category filter chips
- Result list showing product name and category

## Tech stack
Flutter (Material 3)

## Run
1. Open this folder in VS Code (**File > Open Folder**).
2. In a terminal run `flutter pub get`.
3. Pick a device (Android phone, emulator or Chrome) from the bottom-right corner.
4. Press **F5** or run `flutter run`.
