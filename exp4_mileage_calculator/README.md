# Experiment 4: Car Mileage Calculator

Calculates a car's fuel efficiency from distance and fuel used.

## Features
- Numeric input fields with form validation
- Fuel type dropdown
- Calculate and Reset actions

## Tech stack
Flutter (Material 3)

## Run
1. Open this folder in VS Code (**File > Open Folder**).
2. In a terminal run `flutter pub get`.
3. Pick a device (Android phone, emulator or Chrome) from the bottom-right corner.
4. Press **F5** or run `flutter run`.
