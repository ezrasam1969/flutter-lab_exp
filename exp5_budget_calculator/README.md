# Experiment 5: Personal Budget Calculator

Track monthly income against expenses with a live budget status.

## Features
- Set monthly income (₹)
- Add and remove expenses
- Live balance and budget status indicator
- State management with `provider`

## Tech stack
Flutter, provider

## Run
1. Open this folder in VS Code (**File > Open Folder**).
2. In a terminal run `flutter pub get`.
3. Pick a device (Android phone, emulator or Chrome) from the bottom-right corner.
4. Press **F5** or run `flutter run`.
