# Experiment 6: Student Records (SQLite)

Local CRUD app storing student records in an on-device SQLite database.

## Features
- Add students: name, register number, department, CGPA
- Unique register-number constraint with friendly error
- Persistent storage with `sqflite`
- Student list view

## Tech stack
Flutter, sqflite, path

## Run
1. Open this folder in VS Code (**File > Open Folder**).
2. In a terminal run `flutter pub get`.
3. Pick a device (Android phone, emulator or Chrome) from the bottom-right corner.
4. Press **F5** or run `flutter run`.
